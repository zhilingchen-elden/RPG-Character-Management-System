# RPG Character Management System

A Python-based RPG character management system developed as an independent programming project.

## Features

- Character creation and management
- Health and damage system
- Experience and leveling system
- Character abilities and interactions
- Battle mechanics
- CSV-based character and battle data

## Technologies

- Python
- Object-Oriented Programming
- CSV data handling

## What I Learned

This project helped me practice object-oriented programming, program design,
debugging, data handling, and building a larger Python program with multiple
features.
